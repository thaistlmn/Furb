# Estudos de Java & POO

Repositório dedicado à prática de **Programação Orientada a Objetos** e **Testes Unitários** em Java.

---

## Conteúdos Praticados

- **Encapsulamento & Abstração:** Proteção de dados com getters, setters e construtores.
- **Herança & Polimorfismo:** Reutilização de código (`super`) e sobrescrita de métodos (`@Override`).
- **Tratamento de Exceções:** Validação de regras de negócio com `IllegalArgumentException` e exceções personalizadas.
- **Testes Unitários (JUnit 5):** Validação de regras com `assertEquals`, `assertTrue` e `assertThrows`.

---

## Tecnologias

- **Linguagem:** Java 21
- **Testes:** JUnit 5
- **IDE:** Eclipse
