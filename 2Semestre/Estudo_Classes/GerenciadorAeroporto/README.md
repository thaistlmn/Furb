# Sistema de Gerenciamento Aeroportuário

Um sistema em Java desenvolvido para automação e controle de operações aeroportuárias, englobando o cadastro e a gestão de aeroportos, voos e aeronaves com validação rigorosa de dados.

---

## Sobre o Projeto

O objetivo deste projeto é aplicar os conceitos de **Programação Orientada a Objetos (POO)** em Java para simular a infraestrutura e o fluxo de operações de um aeroporto. 

O sistema permite cadastrar e vincular aeronaves a voos específicos, gerenciar capacidades e horários, além de fornecer uma interface interativa para consultas e listagens.

---

## Funcionalidades Principais

- **Gestão de Aeronaves e Voos:** Cadastro, consulta e controle de rotas, códigos de identificação e capacidades.
- **Validação de Dados & Exceções:** Garantia de integridade das informações (ex: capacidade válida, códigos de voo) utilizando tratamento de exceções.
- **Interface Interativa:** Navegação e entrada de dados amigáveis via caixas de diálogo interativas (`JOptionPane`).
- **Consultas e Relatórios:** Busca rápida de voos disponíveis e detalhes das aeronaves vinculadas.

---

## Tecnologias e Conceitos Utilizados

- **Linguagem:** Java
- **Interface de Usuário:** Swing (`JOptionPane`)
- **Paradigma POO:** Encapsulamento, Abstração e Associação de Classes (`Aeroporto`, `Voo`, `Aeronave`, `SistemaAero`)
- **Tratamento de Exceções:** Validação de entradas com `IllegalArgumentException`
- **Estruturas de Dados:** Manipulação de coleções de objetos em memória
- **IDE:** Eclipse
