# Exercícios de Java 

Repositório com exercícios práticos de Java desenvolvidos para fixação de conceitos fundamentais da linguagem, com foco em:

* **Manipulação de Listas (`List`, `ArrayList`)**: Armazenamento, percorrimento e gerenciamento dinâmico de dados.
* **Interfaces Gráficas Simples (`JOptionPane`)**: Interação com o usuário através de caixas de diálogo para entrada e saída de dados.
