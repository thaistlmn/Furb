# Sistema de Gestão de Sorveteria

Um sistema em Java desenvolvido para automação e controle de pedidos em uma sorveteria, cobrindo desde o cadastro e personalização de itens até o processamento financeiro e geração de estatísticas.

---

## Sobre o Projeto

O objetivo deste projeto é aplicar conceitos essenciais de **Programação Orientada a Objetos (POO)** e boas práticas de desenvolvimento em Java para simular o fluxo comercial de uma sorveteria. 

O sistema permite gerenciar sorveteiros, clientes, opções do cardápio e o histórico de pedidos, além de processar cálculos e relatórios de vendas.

---

## Funcionalidades Principais

- **Gerenciamento de Pedidos:** Criação, alteração e cancelamento de pedidos com cálculo automático de totais.
- **Personalização de Produtos:** Adição de sabores, tamanhos, coberturas e acompanhamentos.
- **Relatórios e Estatísticas:** Filtragem de vendas, itens mais pedidos e faturamento do período.
- **Tratamento de Exceções:** Validação de entradas para evitar erros de execução no fluxo da aplicação.

---

## Tecnologias e Conceitos Utilizados

- **Linguagem:** Java
- **Paradigma POO:** Encapsulamento, Herança, Abstração e Associação entre classes (`Pedido`, `Sorvete`, `Controle`, etc.)
- **Java Streams & Lambdas:** Manipulação e filtragem eficiente de coleções/listas de dados
- **Tratamento de Erros:** Estruturas `try-catch` e exceções personalizadas
- **IDE:** Eclipse (ou IntelliJ / VS Code)
